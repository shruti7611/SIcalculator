
# Simple Interest Calculator

## Description

This project is a simple interest calculator that calculates the simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:

- **Principal (P)** = Initial amount of money
- **Rate (R)** = Rate of interest per year
- **Time (T)** = Time period in years

## Example

If:

- Principal = 1000
- Rate = 5%
- Time = 2 years

Then:

Simple Interest = (1000 × 5 × 2) / 100 = 100

So, the simple interest is **100**.

## Features

- Easy to use
- Calculates simple interest quickly
- Takes principal, rate, and time as inputs
